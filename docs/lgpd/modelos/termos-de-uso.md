# Termos de uso da AgroValid (rascunho)

> Rascunho de 05/11/2026. Revisão jurídica pendente.

1. **O serviço.** Pré-diagnóstico socioambiental a partir de bases públicas. É uma triagem: **não é certificação, laudo nem declaração de conformidade** (EUDR, AB+S ou outra).
2. **Conta.** Pessoal e intransferível. O administrador da organização responde por quem convida. MFA obrigatório para administradores.
3. **Uso permitido.** Atendimento dos produtores da própria organização, com base legal para os dados enviados.
4. **Proibido.** Tentar acessar dados de outra organização; automatizar acesso fora da API e dos limites; contornar a segurança; enviar dados sem base legal; usar o resultado para discriminar o titular.
5. **Limites de uso.** A plataforma limita requisições por usuário e por organização.
6. **Fontes públicas.** Podem ter atraso, erro ou indisponibilidade; a ficha mostra a data de cada fonte e o que não foi verificado.
7. **Responsabilidade.** [cláusula a definir com o jurídico].
8. **Dados pessoais.** Conforme a política de privacidade e o contrato de operador com a organização.
9. **Encerramento.** Dados da organização apagados no prazo do contrato; exportação disponível antes.
10. **Foro e lei.** Lei brasileira; foro [a definir].
